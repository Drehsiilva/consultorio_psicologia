# Landing Page - Consultório de Psicologia Dra. Neide Almeida

Este projeto consiste em uma landing page responsiva, desenvolvida com HTML, CSS e JavaScript puros, focada na apresentação profissional e conversão de pacientes para atendimento clínico e psicoterapia da Dra. Neide Almeida.

## Tecnologias Utilizadas
- HTML5 (Estrutura semântica e SEO)
- CSS3 (Estilização premium, responsiva e moderna)
- JavaScript Vanilla (Interatividade do formulário, animações de scroll e menu)

## Integração de Formulários
O formulário de contato envia as mensagens diretamente para o e-mail cadastrado usando o serviço **Web3Forms**. 
- A chave de acesso `access_key` configurada no formulário é pública por design do Web3Forms para funcionamento cliente-servidor estático.

## Configuração do Repositório Remoto (GitHub)

Para conectar seu ambiente de desenvolvimento local ao repositório remoto criado no GitHub, execute os seguintes comandos no terminal do seu projeto:

```bash
# 1. Adiciona o repositório remoto sob o nome de 'origin'
git remote add origin https://github.com/Drehsiilva/consultorio_psicologia.git

# 2. Define o nome da branch principal para 'main'
git branch -M main

# 3. Faz o envio do commit inicial para o repositório no GitHub
git push -u origin main
```
